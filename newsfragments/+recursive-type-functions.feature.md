Add computed types: `recursive type fn VTree<const N: usize>() -> * { match N { 0 => Leaf, _ => Node<VTree<{N - 1}>> } }` declares a type computed from type parameters, constants and a `usize` subject, whose arms may evaluate `const fn` payloads. `VTree<3>` is the same type as `Node<Node<Node<Leaf>>>` wherever a type is written; recursion must decrease the subject, and payload faults, cycles and normalization limits are reported where the type is written. See `docs/language/computed-types.md`.
