Rollcall

A membership registry backed by a Poseidon-Merkle root. The SAME circomlib Poseidon (t=3) kernel is proven, end to end, on wasm and EVM/revm in crates/codegen/tests/rollcall_e2e.rs. This page drives that same kernel live in your browser.

Honest about scope (v1): the root-building and membership check below run the REAL compiled Fe kernel (gen/kernel.wasm) live, in this page. The on-chain commit/verify leg is revm, local (not a testnet or mainnet deploy) and was executed at build time, not from this page -- see the evidence ledger below. GPU execution is pending lavapipe (no Vulkan adapter in this environment), and GPU validation itself is currently blocked upstream for this kernel on the pinned Sonatina rev (see the ledger's webgpu row and RUNG4_ASSEMBLY_PLAN.md).

1. Member list

Four field-element members (non-negative integers). Prefilled from the proven end-to-end fixture.

2. Check membership

Substitutes a candidate leaf at an index into the member list and recomputes the root live via the SAME kernel; accept iff it reproduces the committed root. For this fully-known N=4 tree this is the same computation as folding a Merkle sibling path.

3. Four-leg evidence ledger

Fetched from evidence.json, written once per coherent generator run (cargo run -p fe-codegen --features native-backend --example gen_rollcall_evidence), never baked into this page. A verifier re-hashes the artifacts on disk against the recorded SHA-256s and confirms the roots agree across legs (crates/codegen/tests/rollcall_evidence_verify.rs).
