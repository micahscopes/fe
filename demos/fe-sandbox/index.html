Honest S1 status. Client-side now, zero server: the editor highlighting is real tree-sitter (vendored tree-sitter-fe.wasm grammar + highlights.scm via web-tree-sitter, the same trio the fe-web docs ship); the run stage executes committed gen/ artifacts through the shipped kernel-blind runners. GREEN is earned only when a live WebGPU readback equals wasm-in-browser equals the cross-backend pin (Micah's GPU browser); no WebGPU shows honest AMBER (wasm leg still matches the pin).
Later slices. The prebuilt artifacts were produced by cargo run -p fe-codegen --example gen_webgpu_demo (native). Editing the Fe here and recompiling in the page is slice S3 (the fe-sandbox compiler wasm: the 20-site wasm32 port + a wasm-bindgen worker). Diagnostics/squiggles are S4; the in-page language server (hover/completion) is S5.
Editor note. The plan names CodeMirror 6; it was not vendorable in this offline sandbox (npm/esm/unpkg are egress-blocked, no node to build the CM6 monorepo). This overlay editor drives the same real tree-sitter highlight path, so highlighting is not downgraded; CM6 drops in later behind the same element.
