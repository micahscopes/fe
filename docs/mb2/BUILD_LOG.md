## 2026-07-07 - Slice A2: D1 Sub-PR 2 reland (GAT kinds) + acceptance fixtures

Relanded `1abd3951b` and copied the acceptance fixtures. A trait associated
type's kind is now derived from its own generic params.

- `crates/hir/src/analysis/ty/ty_def.rs` `HasKind for TyData::AssocTy` (the arm
  the ladder pins at ~:2065): an explicit kind bound still wins; otherwise the
  kind is a `Kind::Star`-tail arrow chain of length `generic_params.len(db)`.
  `type Ptr<T>` -> `* -> *`; `type Word` -> `*`. Adapted to the post-FCO tree:
  the arrow is built with the FCO `Kind::abs` fold idiom (matching the sibling
  `TraitCtor` arm added by FCO) instead of the 2026-05 manual
  `Kind::Abs(Box::new(..))` loop; `decl.generic_params.len(db)` replaces the old

  those have zero generic params, so the empty fold yields `Kind::Star`,
  byte-identical to the old `unwrap_or(Kind::Star)`. The FCO `ConstraintTerm` /
  `TraitCtor` arms are untouched.
